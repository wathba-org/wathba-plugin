# Wathba Dev marketplace

This branch is generated by `.github/workflows/publish-dev.yml` from the
`dev` source branch. Do not edit it: change `plugin.config.json` or `src/`
through a pull request into `dev` instead.

It points at the Wathba development environment (`https://apidev.wathba.sa/mcp`).

## Claude Code

```text
/plugin marketplace add wathba-org/wathba-plugin#dev-marketplace
/plugin install wathba-dev@wathba-development
```

Then run `/mcp`, choose `wathba-dev` and sign in. Turn on updates under
`/plugin` → Marketplaces → `wathba-development` → Enable auto-update.

## Codex and the ChatGPT desktop app

```sh
codex plugin marketplace add wathba-org/wathba-plugin --ref dev-marketplace
codex plugin add wathba-dev@wathba-development
```

Installing from the app's Plugins page starts sign-in; in a terminal run
`codex mcp login wathba-dev`.

## Gemini CLI

```sh
git clone --branch dev-marketplace https://github.com/wathba-org/wathba-plugin wathba-dev-extension
gemini extensions install ./wathba-dev-extension
```

Then run `/mcp auth wathba-dev` in Gemini CLI and sign in. To update, pull the
clone, then run `gemini extensions update wathba-dev`. Install either this or
the production extension, not both: Gemini CLI keeps only one `wathba` skill.

## Cursor

Copy `plugins/wathba-dev` to `~/.cursor/plugins/local/wathba-dev` and run
**Developer: Reload Window**, then sign in to the `wathba-dev` server from
Cursor's MCP settings.

## Moving from the old DEV marketplace

The marketplace keeps its name, so remove the old one first:

```text
/plugin marketplace remove wathba-development          # Claude Code
codex plugin marketplace remove wathba-development     # Codex
```

Then add this branch as above, sign in, and check that only one `wathba-dev`
server is listed (`/mcp` in Claude Code, `codex mcp list` in Codex).
